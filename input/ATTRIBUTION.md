# Sample input image

`selfie.jpg` is the official presidential portrait of Barack Obama
(Pete Souza, White House, December 2012), downscaled to 720×900.

* Source: https://commons.wikimedia.org/wiki/File:President_Barack_Obama.jpg
* Licence: **Public domain** — a work of the United States federal government
  prepared by an officer or employee as part of their official duties
  (17 U.S.C. § 105).

It is used here because reverse-image search only produces meaningful results
for images that are actually indexed on the public web. A private individual's
selfie will typically return no matches at all — see "Limitations" in the
main README.

To run the pipeline on your own image, pass it explicitly:

    python main.py --image path/to/your-image.jpg
